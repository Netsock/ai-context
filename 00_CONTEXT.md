# AI Context Protocol

## Purpose

This repository is a minimal public context layer for AI systems working with the user and SalesSeeds.

It extends ordinary AI personalization with shared, public-safe context and reasoning rules.

It is not a public copy of the private Knowledge OS.

## Security boundary

Keep the following private unless the user explicitly provides them for the current task:

- Discussions
- Observations
- Concepts derived from internal discussion
- Knowledge derived from internal work
- customer-specific context
- internal financial information
- unpublished strategy
- personal or confidential information
- private Knowledge OS contents

Do not reconstruct, infer, or guess private material from public context.

## What belongs here

This repository may contain:

- public-safe personalization context
- stable public company context
- definitions needed for consistent interpretation
- reasoning and judgment rules
- instructions describing how AI should handle uncertainty, evidence, context, and decisions

## What does not belong here

This repository must not be used to preserve the substance of private reasoning, research, learning, or knowledge creation.

In particular, do not publish internal Discussion, Observation, Concept, or Knowledge content merely because it has been summarized or distilled.

Distillation does not automatically make private knowledge public.

## Reasoning priority

When company-specific context is supplied, apply the following principles:

1. Explicit current context takes precedence over older information.
2. Explicit decisions take precedence over proposals or interpretations.
3. Evidence and observations must be distinguished from interpretation.
4. Do not invent company-specific facts to fill gaps.
5. Do not silently resolve material ambiguity.
6. General knowledge may support analysis, but must not be represented as company-specific fact.
7. If required private context is unavailable, state that limitation.

## Canonical source

The private Knowledge OS is the canonical source for internal knowledge.

This public repository only defines the shared public context and rules that may safely cross AI-provider boundaries.

## Cross-AI principle

Assume that any content in this repository may be read by multiple AI providers and by the public internet.

Only place information here when that cross-provider and public exposure is acceptable.
